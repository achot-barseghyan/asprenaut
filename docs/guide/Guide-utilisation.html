1L'application en bref

L'application garde la trace de qui a pris quel matériel, pour quelle sortie, et s'il est revenu. Chaque équipement porte une étiquette QR ; on la scanne au départ et au retour. Tout le reste (révisions à prévoir, compteur d'utilisation, bilan de fin de saison) se calcule à partir de ces scans.

Elle fonctionne sur un seul PC Windows, sans internet. Les données restent sur ce PC.

Les écrans du menu de gauche

ÉcranÀ quoi il sert
SortiesPage d'accueil. Sorties en cours, sorties clôturées, modèles de sortie. On y crée une nouvelle sortie.
InventaireTout le matériel du club, son état, sa prochaine révision, son nombre d'utilisations.
ManuelsLes notices PDF des fabricants, consultables et imprimables.
MembresAdhérents, moniteurs et classes (Niveau 1, Niveau 2…).
HistoriqueLe journal de tout ce qui s'est passé, et la vie de chaque équipement.
Bilan de saisonChiffres de la saison pour l'assemblée générale, exportables en PDF.
RévisionsRévisions, TIV, requalifications, réparations et envois chez les prestataires.
ParamètresDeux onglets : Paramètres (fonctionnement de l'application) et Configuration du club (club, types de sortie, prestataires…).

Le bouton Réduire le menu, en bas du menu, ne garde que les icônes pour laisser plus de place.

Les messages de l'application

Après chaque scan, un bandeau s'affiche avec un son : vert = c'est fait, jaune = c'est fait mais attention (révision dépassée…), rouge = refusé, rien n'a changé. Il suffit de lire le message : il dit quoi faire.

A

Installer et configurer

Pour la personne qui prépare l'application avant que les bénévoles ne s'en servent. Comptez une soirée, surtout pour saisir le matériel et importer les adhérents.

2Installer l'application

Ce qu'il faut

  • Un PC sous Windows 10 (version 1809 ou plus récente) ou Windows 11, 64 bits. Rien d'autre à installer.
  • Un pistolet scanner USB qui lit les QR codes, en mode « clavier » (le réglage d'usine de la plupart des pistolets). Un téléphone utilisé comme clavier Bluetooth fonctionne aussi.
  • Des étiquettes QR sur le matériel (médailles, autocollants). Voir le chapitre 5 pour leur contenu.

Installation

  1. Copiez le fichier de l'application (un seul fichier .exe) dans un dossier du PC, par exemple C:\Matériel du club\. Évitez le Bureau et les clés USB.
  2. Faites un clic droit sur le fichier › Envoyer vers › Bureau (créer un raccourci), pour que les bénévoles le trouvent facilement.
  3. Double-cliquez. Au tout premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires puis Exécuter quand même.

L'application s'ouvre sur l'écran Sorties, vide. Les catégories de matériel (Blocs, Gilets, Détendeurs, Combinaisons, Palmes, Masques, Ordinateurs, Autre), six types de sortie (Piscine, Fosse, Mer, Lac, Baptême, Autre) et quatre classes (Niveau 1 à 4) sont déjà créés : vous pourrez les modifier.

Où sont les données ?

Toutes les données sont rangées dans le dossier %LOCALAPPDATA%\Asprenaut\ du compte Windows (tapez ce chemin dans la barre d'adresse de l'explorateur) :

Fichier ou dossierContenu
materiel.dbLa base de données : matériel, sorties, membres, historique.
parametres.jsonLes réglages (dont le code gestionnaire, chiffré).
Sauvegardes\Une copie automatique de la base à chaque lancement (les 20 dernières).
Manuels\Les notices PDF ajoutées.
erreurs.logLe détail technique des erreurs, utile pour un dépannage.
Un seul compte Windows

Les données sont propres au compte Windows. Si plusieurs comptes existent sur le PC, utilisez toujours le même pour l'application, sinon chacun verra une base différente.

Paramètres › Configuration du club › Club

C'est la première chose à faire : le nom du club apparaît en haut du menu, sur l'écran d'accueil et sur tous les documents imprimés (bilan, registre des contrôles, fiches de suivi).

ChampConseil

Club qui reçoit l'application d'un autre club

L'application peut être livrée avec le nom et le logo du club qui l'a créée. Remplacez-les tous les deux ici avant toute utilisation.

4Protéger avec un code gestionnaire

Paramètres › Sécurité · mode gestion

Sans code, tout le monde peut tout faire. Avec un code de 4 à 6 chiffres, l'application démarre en mode consultation : les bénévoles font les sorties normalement, mais les actions sensibles demandent le code.

Libre, sans code

  • Créer ou modifier une sortie en préparation
  • Scanner au départ et au retour, valider le départ
  • Clôturer une sortie où tout est rendu
  • Signaler un problème « à surveiller »
  • Consulter tous les écrans, tester le pistolet
  • Faire une sauvegarde

Code demandé

  • Ajouter ou modifier du matériel, des membres
  • Révisions, atelier, séances TIV
  • Supprimer une sortie
  • Changer les utilisations d'une sortie
  • Mettre hors service, rendre un manquant après clôture
  • Tous les paramètres, restaurer une sauvegarde

Un bouton protégé porte une petite pastille jaune avec un cadenas. En cliquant dessus, un pavé de chiffres s'ouvre ; une fois le code tapé, le mode gestion reste ouvert (carte en bas du menu) jusqu'à :

  • une durée sans activité, réglée par « Rester déverrouillé » : 5, 15 (par défaut), 30 ou 60 minutes ;
  • la fermeture de l'application (option « Verrouiller à la fermeture ») ;
  • un clic sur la carte du mode gestion dans le menu.

Après 5 codes faux d'affilée, la saisie est bloquée une minute. Pour changer ou retirer le code, l'ancien est demandé.

Code oublié

Fermez l'application, ouvrez le fichier %LOCALAPPDATA%\Asprenaut\parametres.json avec le Bloc-notes, supprimez la ligne qui commence par "CodeGestionnaire", enregistrez, relancez. L'application n'a plus de code : définissez-en un nouveau.

Un conseil : notez le code dans un endroit sûr connu du bureau, et ne le donnez qu'aux responsables matériel.

5Régler le pistolet scanner

Paramètres › Pistolet scanner

Tester

  1. Branchez le pistolet sur un port USB. Windows le reconnaît comme un clavier, sans pilote.
  2. Cliquez sur Tester le pistolet et scannez une étiquette.
  3. L'application affiche le code lu. S'il est correct, le pistolet est prêt.

La plupart des pistolets tapent le code puis la touche Entrée. Ceux qui n'envoient pas Entrée fonctionnent aussi : l'application reconnaît la frappe très rapide du pistolet et valide seule après un court instant. À la main, il faut taper le code puis appuyer sur Entrée.

Le code lu est faux (lettres changées, « & » à la place de « 1 »…)

Le pistolet est réglé en clavier américain (QWERTY) alors que le PC est en AZERTY. Scannez la carte de réglage « French keyboard » / « Clavier français » du manuel du pistolet.

Que mettre dans les étiquettes QR ?

Deux formats sont compris :

Contenu du QR codeCe que lit l'application
A24 ou BLOC-031Le code tel quel (espaces retirés, mis en majuscules).
(Detendeur) A24 Mon Club 71-0025Format « médaille » : le code est le mot qui suit la parenthèse (A24), le type entre parenthèses aide à choisir la catégorie d'un équipement inconnu. La suite est libre (nom du club, numéro…).

Choisissez des codes courts et uniques. La convention proposée par l'application :

  • A01, A02… détendeurs adultes ; E01… détendeurs enfants ; S01… gilets stab ;
  • pour le reste, un préfixe par catégorie : BLOC-001, COMBI-001…

Quand on crée un équipement, l'application propose le code suivant dans la même forme (A24 → A25, BLOC-034 → BLOC-035).

Les QR codes se fabriquent avec n'importe quel générateur gratuit ; des médailles gravées résistent mieux à l'eau et au chlore que des autocollants.

6Saisir le matériel

Inventaire › Ajouter un équipement (code demandé)

La méthode la plus rapide : scanner

Scannez une étiquette au départ d'une sortie : si le code est inconnu, l'application ouvre la fiche de création avec le code déjà rempli et la catégorie devinée. Il ne reste qu'à compléter.

La fiche d'un équipement

ChampRemarque
Code, nom, catégorieObligatoires. Le nom sert aussi de « modèle » pour le compteur d'utilisation (chapitre 9) : donnez le même nom aux équipements identiques.
TailleSert à repérer les tailles qui manquent dans le bilan de saison.
Marque, modèle, n° de sériePour les registres. Pour un détendeur : premier étage, deuxième étage, octopus, manomètre, montage étrier ou DIN.
Dernière révisionSaisissez la date de la dernière révision connue : l'application calcule la prochaine.
Dates de TIV et de requalificationPour les blocs uniquement.
NitroxPour les blocs et détendeurs. Au départ d'une sortie nominative, seul un adhérent certifié nitrox peut le prendre.

Catégories

Dans la fiche, la liste des catégories permet d'en créer une nouvelle (nom, pictogramme, couleur) et de supprimer celles qui ne servent à rien. Une catégorie utilisée par un équipement ne peut pas être supprimée.

Pour que les révisions se calculent bien

Gardez les noms de catégorie qui commencent par « Blocs » pour les blocs (TIV et requalification), « Détendeurs » et « Gilets » : les délais de révision et les tuiles de problèmes sont réglés d'après ces noms.

Modifier, réformer

Le crayon de la colonne Actions modifie la fiche. Un équipement ne se supprime pas : passez son état à Réformé. Il disparaît des sorties et des révisions mais reste dans l'historique.

Manuels des fabricants

Manuels › Ajouter : choisissez le PDF, indiquez la marque, la catégorie et, si vous voulez, le sommaire (une ligne par section, page à la fin : 8.2 Entretien ; 17) et le délai de révision du fabricant. Le manuel est relié automatiquement aux équipements de la même marque et de la même catégorie, et un bouton Manuel apparaît sur leurs lignes au départ et au retour.

7Membres : moniteurs, classes, adhérents

Membres — trois onglets. Ajouter ou modifier demande le code.

OngletRôle
AdhérentsLes plongeurs du club. Ils ne sont jamais responsables d'une sortie, mais reçoivent le matériel dans les sorties nominatives (chapitre 12).
MoniteursLes encadrants, responsables des sorties. Niveau d'encadrement (E1… MF2), téléphone, case Inspecteur TIV (seuls les inspecteurs peuvent enregistrer une TIV).
ClassesUn groupe en formation (Niveau 1, Niveau 2…) peut être responsable d'une sortie comme un moniteur. Abréviation de 4 lettres au plus et couleur de pastille.

On ne supprime pas un membre : on le désactive. Il n'est plus proposé mais reste dans l'historique.

Importer les adhérents depuis Excel

  1. Onglet Adhérents › Modèle Excel à remplir : enregistrez le classeur proposé. Il contient les bonnes colonnes, des listes déroulantes et un mode d'emploi.
  2. Remplissez-le (ou collez-y l'export de votre logiciel de licences). Seules les colonnes Nom et Prénom sont obligatoires ; Formation en cours, Licence, Téléphone, Nitrox et CACI valable jusqu'au sont facultatives.
  3. Importer et choisissez le fichier (.xlsx ou .csv). Un adhérent déjà connu (même licence, sinon même nom et prénom) est mis à jour ; les autres sont ajoutés ; personne n'est retiré.

Vous pouvez réimporter le fichier à chaque début de saison : une case vide ne change rien.

CACI (certificat médical)

Cochez CACI et indiquez sa date de fin. Un CACI expiré empêche l'adhérent de recevoir du matériel dans une sortie nominative ; une pastille « CACI BIENTÔT » apparaît 30 jours avant la fin, et le filtre CACI à renouveler les liste. Si vous ne gérez pas les CACI, laissez la case décochée : aucun contrôle n'est fait.

8Types de sortie et règles

Types de sortie et utilisations

Paramètres › Configuration du club › Types de sortie et utilisations

Ajoutez, renommez, réordonnez les types (40 caractères au plus). Pour chaque type :

  • Utilisations par sortie (1 à 10) : combien « compte » une sortie de ce type pour l'usure du matériel. Par défaut : piscine, fosse, baptême, autre = 1 ; lac = 2 ; mer = 4.
  • Nom de l'adhérent à chaque scan : la sortie devient nominative (chapitre 12). Coché d'origine pour Mer et Lac.

Un type déjà utilisé ne se supprime pas : l'œil le masque (il n'est plus proposé, les anciennes sorties le gardent).

Modèles de sortie

Sorties › Modèles › Nouveau modèle

Pour les sorties qui reviennent chaque semaine (« Piscine du mardi ») : jour habituel, type, lieu, responsable, notes. Sur l'écran Sorties, le Démarrage rapide propose les prochains modèles : un clic sur Créer la sortie et l'on passe directement au scan.

Affichage

Paramètres › Affichage : thème sombre ou clair. Les sons des scans se coupent dans Paramètres › Pistolet scanner (« Sons de confirmation »).

9Révisions, prestataires et TIV

Délais

L'application calcule les échéances selon ces délais, modifiables dans les paramètres :

ContrôleDélai par défaut
TIV des blocs12 mois
Requalification des blocs6 ans (vaut aussi TIV)
Révision des détendeurs24 mois
Révision des giletspas de date obligatoire (suivi par le compteur d'utilisation)
Autres catégories12 mois
Résultat « à surveiller »nouveau contrôle dans 6 mois

Si un manuel du fabricant indique un autre délai, l'écran Manuels le signale et propose Régler le club pour reprendre celui du fabricant.

Compteur d'utilisation

Paramètres › Configuration du club › Compteur d'utilisation

Chaque retour ajoute les utilisations de la sortie au compteur de l'équipement, remis à zéro à chaque révision. Fixez un seuil par catégorie (100 par défaut pour détendeurs et gilets, 0 = désactivé), et si besoin un seuil propre à un modèle ou à un équipement. À 90 % du seuil, l'équipement est proposé dans Révisions ; au seuil, il part avec un avertissement, ou il est refusé si vous activez Bloquer au seuil.

Prestataires

Paramètres › Configuration du club › Prestataires : les magasins et organismes à qui vous envoyez du matériel. Ils sont proposés lors d'un envoi. On ne les supprime pas, on les désactive.

Séance TIV

Paramètres › Configuration du club › Séance TIV : planifiez la prochaine séance (date, heure, lieu, inspecteurs). Les blocs dont la TIV tombe au plus tard 30 jours après sont listés « à préparer ». Si votre club ne fait pas ses TIV lui-même, coupez Afficher dans Révisions.

Problèmes signalés

Paramètres › Configuration du club › Problèmes signalés : les tuiles de causes proposées quand un bénévole signale un problème (« Débit continu », « Fuite »…), par catégorie. Ajoutez, réordonnez, et cochez Précision obligatoire pour une tuile comme « Autre ».

10Sauvegardes et changement de PC

Paramètres › Données et sauvegardes

L'application copie sa base à chaque lancement, sur le même disque. Cela protège d'une fausse manœuvre, pas d'une panne du PC ni d'un vol. Pour cela il faut une sauvegarde complète sur une clé USB ou un disque externe.

Sauvegarde complète — une fois par semaine

  1. Branchez une clé USB.
  2. Faire une sauvegarde complète… et choisissez la clé. Un fichier .zip est créé : base, réglages, manuels et logo.
  3. Rangez la clé ailleurs que près du PC.

Au bout de 7 jours sans sauvegarde complète, un bandeau jaune le rappelle sur l'écran Sorties, avec un bouton Faire la sauvegarde ›. Le dossier choisi est reproposé la fois suivante.

Restaurer, ou installer un nouveau PC

  1. Installez l'application sur le nouveau PC (chapitre 2) et lancez-la une fois.
  2. Paramètres › Données et sauvegardes › Restaurer… (code demandé s'il y en a un) et choisissez le .zip.
  3. L'application vérifie le fichier, garde une copie des données actuelles, restaure tout et redémarre.
Préparer sur un autre PC

Vous pouvez tout configurer chez vous (matériel, adhérents, réglages), faire une sauvegarde complète, puis la restaurer sur le PC du club.

Exports

Exporter CSV crée un dossier avec un fichier par table (matériel, sorties, adhérents, révisions…), lisible dans Excel. L'inventaire, l'historique et les utilisations d'un équipement ont aussi leur propre export.

B

Utiliser au quotidien

Pour tous les bénévoles. Le geste de base : scanner chaque équipement quand il part et quand il revient. L'application fait le reste.

Clôturéedans l'historique

1. Créer la sortie

Sorties › Nouvelle sortie, ou un modèle du Démarrage rapide.

  1. Type : cliquez sur une tuile (Piscine, Mer…).
  2. Quand et où : date et lieu ; les raccourcis proposent aujourd'hui, demain, le week-end et les derniers lieux.
  3. Responsable : un moniteur ou une classe.
  4. Règles et notes si besoin.

L'aperçu de droite résume la sortie. Cliquez sur Créer et scanner le matériel.

2. Scanner le départ

Scannez chaque équipement. Il s'ajoute à la liste avec un bip. Pas besoin de cliquer dans le champ : il reste prêt.

  • Scanné deux fois ? Ignoré, « déjà scanné ».
  • Code inconnu ? La fiche de création s'ouvre (code gestionnaire demandé).
  • Hors service ou réformé ? Refusé : laissez-le au local.
  • Révision dépassée ? Il part, avec un message jaune (ou refusé selon les réglages).
  • Erreur ? Le bouton Retirer sur la ligne, tant que le départ n'est pas validé.

Quand tout est scanné : Valider le départ. On peut encore ajouter du matériel ensuite. Les boutons Modifier la sortie et Supprimer (sortie vide) sont en haut à droite.

3. Scanner le retour

Sur l'écran Sorties, carte de la sortie › Scanner le retour. Scannez chaque équipement rendu : il passe dans la colonne « Rendu ». Un équipement d'une autre sortie scanné ici est proposé au retour dans sa sortie.

S'il y a un souci avec un équipement (fuite, sangle cassée), cliquez sur Signaler un problème tout de suite (chapitre 13).

4. Clôturer

Clôturer la sortie. Si tout est rendu, c'est fini. S'il reste du matériel dehors, l'application affiche le nombre et propose Clôturer avec du matériel manquant : ces équipements deviennent Manquants.

Ne pas clôturer trop tôt

Une sortie en cours peut rester ouverte jusqu'au lendemain, le temps que tout le matériel revienne. Elle passe en orange quand le retour tarde.

12Sorties nominatives

Pour les sorties où chacun repart avec son matériel (mer, lac), on note à qui est confié chaque équipement. La sortie affiche le badge « Nom obligatoire à chaque scan ».

  1. Scannez l'équipement. Le panneau « À qui est ce détendeur ? » remplace la zone de scan.
  2. Cliquez sur l'un des derniers adhérents proposés, ou tapez quelques lettres du nom puis Entrée (flèches pour choisir).
  3. Le panneau se ferme, scannez l'équipement suivant.

Tant qu'un équipement attend son adhérent, le scan suivant et la validation du départ sont refusés. Annuler ce scan retire l'équipement en attente.

Refus possibles

  • Adhérent désactivé.
  • CACI expiré.
  • Équipement nitrox pour un adhérent non certifié.
  • Deuxième équipement de la même catégorie pour le même adhérent (« A déjà A12 »). Cette règle se coupe dans la sortie (« Un équipement par catégorie et par adhérent ») avec le code gestionnaire.

Au retour, le nom de l'adhérent s'affiche sur chaque équipement encore dehors. Un manquant garde le nom de la personne qui l'avait pris.

13Matériel manquant et problèmes signalés

Un manquant réapparaît

Il suffit de le scanner : au départ d'une nouvelle sortie, il est noté « retrouvé » dans son ancienne sortie puis part normalement. Depuis une sortie clôturée (ouverte d'un clic depuis l'onglet Clôturées), on peut aussi le scanner ou cliquer Marquer rendu sur sa ligne (code gestionnaire demandé).

Signaler un problème

Au retour (bouton Signaler un problème ou drapeau sur la ligne) ou depuis l'inventaire (drapeau de la colonne Actions) :

  1. Choisissez la cause (tuile) et ajoutez une précision si besoin.
  2. Choisissez la gravité :
    • À surveiller : l'équipement reste en service, une pastille le signale dans l'inventaire.
    • Hors service : il ne part plus (code gestionnaire demandé).

Le problème apparaît en tête de la colonne « À prévoir » des Révisions. La prochaine intervention enregistrée le ferme et, si c'est lui qui avait mis l'équipement hors service, le remet en service.

14Suivre les révisions

Révisions — réservé en pratique au responsable matériel (code demandé pour toute action).

ColonneContenu et actions
1 · À prévoirCalculée : échéance proche ou dépassée, 90 % du compteur, problème signalé, intervention prévue. Actions : Réparer au club, Envoyer chez un prestataire, ou séance TIV pour un bloc.
2 · Réparation interneTravail fait au club, et la carte de la prochaine séance TIV. Enregistrer le résultat.
3 · À envoyerPrêt à partir chez le prestataire. Marquer comme parti le jour du départ (l'équipement passe hors service).
4 · Chez le prestataireEn réparation à l'extérieur ; en rouge si la date de retour prévue est passée. Retour du prestataire.
5 · FaitLes interventions des 30 derniers jours. Archiver tout pour faire le ménage (rien n'est supprimé).

Enregistrer une intervention

Date, nature, intervenant (inspecteur obligatoire pour une TIV), résultat et description :

  • Conforme : la prochaine échéance est recalculée, le compteur repart à zéro.
  • À surveiller : nouveau contrôle dans 6 mois.
  • Refusé : l'équipement passe hors service.

Le bouton Ajouter une intervention en haut de page permet de prévoir une intervention (« Changer la membrane ») ou d'en noter une déjà faite. Scanner une étiquette ouvre directement ce panneau.

Registre PDF imprime le registre des contrôles, à présenter en cas de vérification.

Les colonnes peuvent être repliées avec l'œil de leur en-tête pour se concentrer sur les autres.

15Inventaire, fiche de suivi, manuels

Inventaire

Filtrez par catégorie (puces en haut) et cherchez par code, nom, marque, modèle ou numéro de série. La colonne Utilisation montre le compteur (« 64 / 80 utilisations », jaune à 90 %, rouge au seuil) ; le lien Voir les sorties détaille chaque sortie de l'équipement.

Colonne Actions : fiche de suivi EPI, signaler un problème, modifier. Exporter CSV exporte les lignes affichées.

Fiche de suivi EPI

Clic sur le nom d'un équipement (ou double-clic, ou Entrée). La fiche réunit ses composants (premier étage, deuxième étage, octopus, manomètre), toutes ses interventions, ses problèmes signalés, et s'imprime en PDF avec Imprimer la fiche.

Manuels

Ouvrez une notice, cliquez sur une section du sommaire pour y aller, imprimez une partie ou tout. Les bénévoles peuvent les consulter sans code.

16Historique et bilan de saison

Historique

Le journal, jour par jour, de tous les départs, retours, contrôles et modifications. Période : 7 jours, 30 jours, saison (depuis le 1er septembre) ou tout. Cliquez sur un code pour voir la vie de l'équipement. Le journal s'exporte en CSV.

Bilan de saison

Saison en cours ou précédente (du 1er septembre au 31 août). L'écran montre :

  • le nombre de sorties et d'équipements sortis, mois par mois ;
  • le matériel perdu et retrouvé ;
  • les groupes en tension (catégorie et taille presque toujours dehors lors des grosses sorties) : utile pour décider des achats ;
  • le matériel peu sorti (moins de 3 sorties) ;
  • les contrôles faits par famille.

Le bouton d'export crée un PDF prêt à présenter à l'assemblée générale.

Comment l'enregistrer en PDF

Les documents passent par l'imprimante « Microsoft Print to PDF », présente sur tous les Windows 10 et 11. Si elle a été supprimée : Paramètres Windows › Imprimantes › Ajouter une imprimante.
